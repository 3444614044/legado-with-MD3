# Android TV / 遥控器使用指南

本应用可在 Android TV（大屏）上安装并使用标准遥控器（D-pad）完整操作。
手机/平板的交互与视觉不受本文改动影响。

## 假设与范围

- 目标设备：Android TV 1080p+，标准遥控器（方向键 / 确认 / 返回，部分遥控器带菜单键）。
- 本次改动：启动器与功能声明、焦点可见性、遥控器按键补全、大屏侧边导航。
- 不在范围：漫画阅读器的手势翻页适配、Leanback 精选内容源、遥控器语音搜索、横屏双页排版。

## 遥控器按键映射

| 按键 | 主界面 | 阅读页 |
| --- | --- | --- |
| 方向键 ↑↓←→ | 在可聚焦项之间移动焦点（焦点项显示主题色描边） | 上/下/左 = 上一页，右 = 下一页 |
| 确认 / OK（DPAD_CENTER、ENTER） | 打开聚焦的卡片/按钮 | 呼出阅读菜单（对应屏幕中央点按手势） |
| 返回（BACK） | 退出/上级页面 | 关闭菜单或上级页面 |
| 菜单（MENU，部分遥控器） | 刷新书架（全量目录更新） | 呼出/关闭阅读菜单 |
| 翻页键（PAGE_UP / PAGE_DOWN） | — | 上一页 / 下一页 |
| 媒体键（上一首/下一首） | — | 上一章 / 下一章 |
| 音量键 | 系统音量 | 可在阅读设置中改为翻页（默认仍为音量） |

## 大屏（TV/平板）行为

- 电视上默认使用**侧边导航栏（Navigation Rail）**；若在应用设置中把「平板界面」显式设为
  「关闭」，则仍按设置使用底部导航。
- 阅读页方向由系统的屏幕方向决定；Manifest 未锁定方向，TV 横屏可正常使用。
- 应用在 TV 启动器中的横幅为 `res/drawable/tv_banner.xml`（可按需替换品牌素材）。

## 涉及文件

- `AndroidManifest.xml`：`touchscreen` 非必需、`leanback` 可选、`LEANBACK_LAUNCHER` 入口、`banner`
- `res/drawable/tv_banner.xml`：TV 启动器横幅
- `ui/widget/components/focus/AppFocusRing.kt`：D-pad 焦点高亮描边（仅电视生效）
- `ui/main/MainActivity.kt`：TV 强制侧栏导航；菜单键 → `FlowEventBus UP_ALL_BOOK_TOC` 刷新书架
- `ui/book/read/ReadBookController.kt`：确认键/回车 → 呼出阅读菜单
- 焦点描边应用点：底部导航项、侧栏导航项、书架书籍卡片、顶栏图标按钮

## 已知限制

1. 焦点描边依赖 Compose 焦点事件向祖先传播；若个别 M3/Miuix 组件内部自行消费焦点事件，
   该项可能无描边（操作不受影响，只是缺视觉提示），遇到后按点补 `appFocusRing` 即可。
2. 菜单键（MENU）并非所有遥控器都具备；无菜单键的遥控器可进阅读页后用确认键操作，
   书架刷新可退出重进（回到前台即刷新）。
3. 漫画（图片）阅读器仍为触屏手势操作，遥控器仅能系统返回。
4. 焦点环仅在 `isTv` 设备启用；手机外接键盘时不会显示（如需放开，修改 `appFocusRing`
   的 `enabled` 默认值即可）。

## 验证清单（TV 模拟器/真机）

```bash
# 构建并安装
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk

# TV 模拟器（AVD: Android TV 1080p）上的检查项：
# 1. 启动器出现应用图标与横幅
# 2. 方向键可在书架卡片、底部/侧栏导航间移动，焦点有描边
# 3. 确认键打开书籍；阅读页方向键翻页、确认键呼出菜单
# 4. 有菜单键的遥控器：主界面按菜单键，书架刷新
# 5. 返回键逐级退出，无焦点陷阱（任何界面按方向键都可继续操作）
```
